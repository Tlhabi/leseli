# Sesotho review checklist · Lethathamo la ho hlahloba Sesotho

The Sesotho in Leseli was written in **Lesotho orthography** (ea, oa, li-, tš, 'm, e.g. *lijo, ntšo, 'mè*).
It must be checked by a first-language Sesotho teacher before learners use it. This is part of participatory design: the school owns the language.

## How to review (on the phone, no computer needed)
1. Teacher area → **Lokisa lithuto / Correct the lessons** → choose a lesson → correct any word → **Boloka**.
2. Teacher area → **Romela litokiso** → send the file to the student team by WhatsApp.
3. The team copies the corrections into `app/content/*.js` and releases a new version.

## Priority (check first)
- [ ] Sesotho subject: all 12 lessons (grammar terms: *lereho, seemeli, sehlakisi, sehokelo, leeketsi*)
- [ ] Riddles (*lilotho*) and proverbs (*maele*): some riddles were written in the traditional style for the app; replace any that are not right with ones the learners' grandparents know
- [ ] Maths words: *kopanya, tlosa, atisa, arola, karoloana, sekhutlo, khutlo-tharo, seatiso, bonngoe/mashome/makholo/likete*
- [ ] Science words: *phoofolo e anyesang, sehahabi, sephela-metsing le fatše, kokoanyana, oksijene*
- [ ] Interface words (buttons): `app/js/i18n.js`
- [ ] Spoken Sesotho: does the read-aloud voice sound understandable? If not, record narration for the most-used lessons.
